# 因子和策略白话手册

这份手册专门解决一个问题：
很多名字很专业，但你只想知道“现在该怎么看、该怎么用”。

---

## 1. 先看状态，不要先看因子

在推荐关注页面，先看每只股票属于哪一组：

1. 突破强势
含义：刚突破近期高点，趋势偏强。
动作：可以重点跟踪，等回踩或放量确认。

2. 强势观察
含义：趋势还不错，但还没到最理想入场点。
动作：放进观察列表，等信号更明确。

3. 回踩布局
含义：强势股回调到均线附近，可能是低风险观察点。
动作：等待“止跌企稳”再考虑计划。

4. 防御止损
含义：趋势走坏或风险偏高。
动作：以防守为主，谨慎新开仓。

5. 暂不交易
含义：信号不清楚或数据不足。
动作：先不动，等下一次刷新。

## 2. 因子白话翻译（按你界面里的分组）

### 技术趋势
1. 均线多头排列
意思：短期线在长期线上方，趋势一般更健康。

2. 距 52 周高点
意思：离一年内高点有多远，越接近通常越强。

3. 60 日趋势斜率
意思：过去 60 天总体是在上坡还是下坡。

4. 20 日突破
意思：是否创了近 20 天新高。

### 动量
1. 20/60/120 日收益率
意思：最近这段时间涨跌幅。

2. 相对行业强度
意思：和同行比，是更强还是更弱。

### 成交量
1. 量比(20日)
意思：最近成交是否明显放大。

2. 成交额变化
意思：资金活跃度在升还是降。

### 估值
1. 市盈率(TTM)
意思：价格相对利润是否便宜，通常越低越便宜。

2. 市净率(PB)
意思：价格相对净资产是否贵，通常越低越便宜。

3. 股息率
意思：分红回报率，高一点对稳健型更友好。

4. 行业估值分位
意思：在自己行业里估值是高位还是低位。

### 财务质量
1. ROE
意思：公司用股东的钱赚钱的效率。

2. 营收增速
意思：主营业务是不是在增长。

3. 资产负债率
意思：杠杆高不高，通常越低越稳。

### 风险控制
1. 60 日年化波动率
意思：价格晃动幅度，越高越刺激也越危险。

2. 120 日最大回撤
意思：过去最惨从高点跌了多少。

3. 换手率
意思：交易活跃度，太高有时代表情绪过热。

4. 连续跌停
意思：短期极端风险信号。

### 资金面
1. 主力资金净流入
意思：大资金是流入还是流出。

### 事件（默认只展示，不参与总分）
1. 财报临近
2. 分红除权
3. 限售解禁
4. 业绩预告

这些事件更多是提示“可能波动”，不是直接买卖信号。

## 3. 回测策略白话翻译

系统当前常见策略：

1. 20 日动量
逻辑：买最近 20 天涨得更好的。
适合：短中线偏进攻。

2. 60 日动量
逻辑：买最近 60 天持续走强的。
适合：比 20 日更稳一点。

3. 120 日动量
逻辑：买中长期趋势更强的。
适合：偏耐心、换手较低。

4. 60 日趋势斜率
逻辑：找“稳步上坡”的标的，不只看涨幅，也看平滑度。
适合：不喜欢大起大落的人。

5. 低波动 60 日
逻辑：优先选择波动更小的标的。
适合：防守型、稳健型。

## 4. 小白最小决策法（只看 3 件事）

如果你觉得信息太多，先只看：

1. 状态分组
先过滤掉 防御止损 和 暂不交易。

2. 趋势 + 风险
优先看：均线多头排列、60 日趋势斜率、最大回撤。

3. 基本面底线
至少确认：ROE 不是很差、营收不是明显下滑。

这三步就能先避开很多明显不合适的标的。

---

## 5. 你可以直接这样问 AI 助手

1. 把这只股票的因子结果翻译成小白能懂的话，只要结论和理由。
2. 这只股票为什么在 回踩布局，不在 突破强势？
3. 请用 保守版 给我一个计划：入场条件、止损条件、失效条件。
4. 如果我只能看 3 个指标，当前这只股票该看哪 3 个？

---

## 6. 重要提醒

1. 因子和策略是“辅助决策”，不是保证盈利。
2. 同一策略在不同市场阶段会失效。
3. 先小仓位验证，再逐步加深使用。
